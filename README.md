# Hlavonožec – web spolku

Responzivní jednostránkový web sestavený z Google Stitch exportů. Navigace posouvá mezi sekcemi, součástí jsou dodaná loga, lokální fonty, mobilní menu a kontaktní formulář napojený na Formspree.

Hotový web tvoří soubory HTML a složka `assets`; na hostingu nepotřebuje framework ani databázi. Kompletní upravitelné zdroje jsou součástí repozitáře.

Aktuální rozsah, ověření a chybějící podklady popisuje [stav projektu](STAV-PROJEKTU.md).
